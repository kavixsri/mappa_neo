## How the Architecture Extends to Segment 3 Without Rewrites
1. **Modular Geospatial Ingestion:** `mappa/pipeline.py` outputs standardized `change_polygons.geojson` and `roads_status.geojson` independently of downstream consumers.
2. **Extensible Neo4j Graph Schema:** Adding hydropower plants, telecom towers, or insured warehouses requires zero schema migration — they are ingested as additional `:Facility {category: 'substation' | 'hydropower' | 'warehouse'}` nodes linked via `[:CONNECTED_TO]` to the same `:Junction` graph.
3. **RBAC-Scoped APIs:** `mappa/security.py` already enforces role-based JWT access (`commander`, `engineer`, `admin`), making it trivial to add a read-only `insurer` or `operator` role subscribed to isolation webhooks.
